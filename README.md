# 喜雅鸟 XIYANIAO 品牌官网

面向年轻男性、女性的时尚个性 PU 腰带品牌静态官网。项目采用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建即可运行。

## 本地预览

```bash
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173`。

## 页面内容

- 品牌主视觉与年轻、无性别产品叙事
- 按女款、男款、中性分类筛选的产品系列
- 产品细节弹窗
- 品牌态度、工艺细节、源头工厂能力
- 合作咨询弹窗与邮件草稿
- 桌面端、平板和移动端响应式布局
- 键盘操作、减少动态效果偏好和语义化页面结构

## 上线前可调整

- 将 `index.html` 中的 `hello@xiyaniao.com` 替换为真实合作邮箱。
- 将示例产品名称、规格、颜色与文案替换为真实产品资料。
- 如产品图库已有正式摄影，替换 `assets/illustrations/` 中的矢量和 `assets/images/` 中的场景图。
- 如需表单直接提交，可接入企业邮箱服务、飞书表单或 CRM，并把当前邮件草稿逻辑替换为接口请求。
